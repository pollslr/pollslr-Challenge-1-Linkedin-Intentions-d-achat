Options — Veille LinkedIn

Ces réglages restent dans le stockage local de votre navigateur. Aucun mot de passe ni cookie LinkedIn n'est demandé : l'outil utilise la session déjà ouverte dans ce navigateur. Tous les autres paramètres (mots-clés, fréquence, fenêtre horaire, volume) se règlent dans la Google Sheet.

Mode test (démonstration sans LinkedIn)

Lancez python3 -m http.server 8765 dans le dossier extension/test. Pages fournies : fixture-resultats.html (résultats factices) et fixture-checkpoint.html (page de vérification → arrêt automatique).
